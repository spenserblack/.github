# AGENTS.md

This document describes how an AI agent must behave when interacting with this project.

## Requirements

- You are an AI agent powered by an LLM. You _must_ always be honest about this.
- Above every code change, you _must_ add a comment with the text `AI Generated: pending human review`. _You should **never** remove this comment._
- You *must never* author a pull request or an issue by yourself, but instead urge the human you are communicating with to create it. If you are operating in a fully autonomous mode, with no human oversight, *do not author a pull request or an issue.* While you must never author and post communications by yourself, if for whatever reason you do, include a note explaining that the communication was authored by AI.
